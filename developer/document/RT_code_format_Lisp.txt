Lisp Identifier Naming
Because Emacs Lisp and Common Lisp support the hyphen character in identifiers, Lisp code utilizes snake-kebab_case. The hyphen acts as the primary word separator. The underscore is reserved strictly as a secondary separator to group logically related portions of an identifier or to denote semantic boundaries, acting as a structural namespace within the symbol (e.g., city-scape_building-height).

Function Call Enclosures
Lisp function calls are exempt from the multi-level enclosure padding rule. The outer parentheses forming a function call receive no padding, even when they contain nested data lists.
Example: (cat 'a 'b '( 2 (4 5)))

The let Form Block Structure
The bindings list must be isolated to emphasize vertical expansion.

The bindings list begins on a new line with an isolated opening parenthesis.

Each binding sits on its own line.

The bindings list closes with an isolated closing parenthesis, vertically aligned with the opening parenthesis.

The body of the let follows on the subsequent line.

The if Form Block Structure
Vertical separation is heavily emphasized for conditional branches.

The condition, the true clause, and the false clause each occupy their own line.

For non-trivial clauses, an empty line is inserted before the true and false clauses to provide distinct visual separation.
