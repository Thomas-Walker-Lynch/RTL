The Intuition (The Ape and the Vine)

Imagine a vine (the container) with grapes (the cells). The machine is a hand resting firmly on a grape. Because the hand is already on a grape, the ape can look at it (read) at any time without checking if it is there. To move (step), the ape must look ahead to ensure another grape exists before letting go. To look ahead without losing the current spot, the ape places a second hand on the same grape (entanglement) and moves it forward.

Topological Foundation (Space vs. Time)

  • A tape is defined by topology, not time. It possesses a leftmost cell and a rightmost cell.
  • Temporal terms like first and last are strictly reserved for traversal order. Conflating structural location (leftmost) with traversal sequence (first) is a fundamental ontological error.

Architecture & Contracts

The TM.el library provides factories (e.g., RT·TM·list·make, RT·TM·buffer-byte·make) that map Elisp containers to a standardized TM interface.

  • The Invariant Read (RT·TM·read): The machine never rests in a void. If a machine exists, it rests on a valid cell. Therefore, reading requires no defensive null checks.
  • The Step Contract (RT·TM·has-right-neighbor): Operations rely on programmer-proven contracts. A programmer must explicitly verify the topology before invoking RT·TM·step.

Memory-Safe Iteration

Sequences are traversed using loops designed to cleanly evaluate boundary conditions alongside current cell work, preventing out-of-bounds steps:

  • Middle-Break Loop: The preferred iterative structure in Elisp (using the RT·loop and RT·break macros), executing the check and break cleanly in the middle of the evaluation.
  • First/Rest Loop: The explicit fallback structure when middle-breaks are unavailable.
  • Recursion: The last preference in Emacs Lisp due to the lack of Tail Call Optimization (TCO), which risks call stack exhaustion.

Concurrency, Entanglement, and Tape Sharing

  • Uniplex (Solo): Provides exclusive access. Destructive operations (mutating the tape structure) are safe.
  • Multiplexed (Entangled): Allows multiple heads to safely share a tape substrate.
  • Entangled Copies (RT·TM·entangled-copy): The primary interface function for lookaheads. It clones a machine state to place a new head on the exact same substrate cell, allowing for non-destructive scans and side-effect-free function calls.
  • Safety of Simultaneous Entangled Machines: Multiple heads can exist simultaneously on the same tape substrate safely if and only if the underlying topology is stable. The container must not undergo structural mutations (deletions or insertions) that would remove a cell currently occupied by a resting machine. In TM.el, this makes simultaneous entanglement natively safe for strings and read-only buffers, but it requires strict guarantees when sharing mutable lists or active buffers without Entanglement Accounting (ea-tm).

Examples

Example 1: Safe Iteration using Middle-Break

This example demonstrates an element-wise comparison between two sequences using RT·TM·entangled-copy for safety and the preferred RT·loop structure.

(defun RT·TM·sequence·eq (tm_substrate tm_target) "Iteratively compare a substrate tape against a target tape." (let ( (tm_substrate-copy (RT·TM·entangled-copy tm_substrate)) (tm_target-copy (RT·TM·entangled-copy tm_target)) ) (let ( (bool_are-eq nil) (bool_target-has-right-neighbor nil) (bool_substrate-has-right-neighbor nil) ) (RT·loop ;; 1. The invariant read (setq bool_are-eq (= (RT·TM·read tm_substrate-copy) (RT·TM·read tm_target-copy))) ;; 2. The pre-guard evaluation (setq bool_target-has-right-neighbor (RT·TM·has-right-neighbor tm_target-copy)) (setq bool_substrate-has-right-neighbor (RT·TM·has-right-neighbor tm_substrate-copy)) ;; 3. The middle break (if (not (and bool_are-eq bool_target-has-right-neighbor bool_substrate-has-right-neighbor)) (RT·break (and bool_are-eq (not bool_target-has-right-neighbor))) (progn ;; 4. Contract fulfilled, safe to step (RT·TM·step tm_substrate-copy) (RT·TM·step tm_target-copy) ))) )))
