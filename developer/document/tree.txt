
Controlled Tile Array Tree

1. Format

1.0. Layer 0 is an indexed bit array.

The leftmost bit of the array has an index of zero.  The index of the rightmost element of an array is called the array's `extent`. 

A bit array with an extent of zero has a total count of 1 bit in it.

The tree codes data. A tree being 'empty' or 'null' is external control state.


1.1. Layer 1, command and tiles

The bit array is formatted as one or more repeated command/tile pairs.

  tree:: <tile>(<command><tile>)+

A command schema is an immutable property of this specification document. To change the schema would be to create a different specification.

The tile extent is a static property of the tree. It can be configured before the tree is created, and then will not changed during the life of the tree.

The leftmost tile appears without a command tag. We give it the name 't0'.

1.2 Command schema

An given tree is 'encoded' by writing down a set of commands and tile values, that when replayed, explain to the reader how to build a copy of the given tree.

A give tree is 'decoded' when said commands are executed, and the tree copy is built.

A tree is decoded by reading the bit array from left to write, i.e. starting with bit index 0.

1.2.1 Depth First schema

Each command has a single argument, that of a tile.


s0. Initialize: 
       stack = ( (t0) )
   
s1. successively apply commands:

 encoding  | command steps
   0       | stack.top().append(ti)  ; append child
           |
  10       | L = (ti)                ; branch
           | stack.top().append(L)
           | stack.push(L)
           |
 110       | stack.top().append(ti)  ; tile completes child list
           | stack.pop()
           |
 111       | L = (ti)                ; branch completes child list
           | stack.top().append(L)
           | stack.pop               ; tail optimization
           | stack.push(L)

s2. End of Tree, EoT, when pop would make the stack empty


(a (b c d (e f g)) h)


             a . h
              /
         b  c  d .
                /
             e f  g

1.2.2 Breadth First schema
Each command has a single argument, that of a tile.

s0. Initialize:
queue = ( (t0) )

s1. successively apply commands:

encoding     | command steps
    0        | queue.front().append(ti)  ; append child
             |
   10        | L = (ti)                  ; branch
             | queue.front().append(L)
             | queue.enqueue(L)
             |
   110       | queue.front().append(ti)  ; tile completes child list
             | queue.dequeue()
             |
   111       | L = (ti)                  ; branch completes child list
             | queue.front().append(L)
             | queue.enqueue(L)
             | queue.dequeue()           ; tail optimization

s2. End of Tree, EoT, when dequeue would make the queue empty

   (a (b c d (e f g)) h)

         a . h
          /
     b  c  d .
            /
         e f  g
